# Hi, I'm Zichen (Joe) Zhu

I'm a Statistics & Computer Science undergraduate at the University of Illinois Urbana-Champaign, graduating in May 2028. I build iOS apps and backend systems, with interests in applied machine learning and quantitative research.

## Selected work

- **[MemoFigure](https://github.com/zichenz7/MemoFigure-Showcase)** — An App Store iPhone app that turns memories and photos into personal 3D keepsakes. I built the SwiftUI client and Node.js backend, including Cloud Run / Cloud Tasks orchestration, task recovery, and 3D previews. [App Store](https://apps.apple.com/us/app/memofigure/id6787197327) · [Engineering overview](https://github.com/zichenz7/MemoFigure-Showcase/blob/main/docs/ENGINEERING.md)
- **[Project Brain](https://github.com/zichenz7/Project-Brain-Showcase)** — A React/TypeScript project-state workspace with GitHub evidence, rule-based suggestions for user review, and revisioned correction history. I implemented signed webhook ingestion, idempotent processing, and transactional persistence in Cloudflare D1. [Engineering overview](https://github.com/zichenz7/Project-Brain-Showcase/blob/main/ENGINEERING.md)
- **[Optiver Explaining Markets](https://github.com/zichenz7/Optiver-Explaining-Markets-Showcase)** — An independent competition project using a Python TF-IDF/Ridge ensemble, quarterly walk-forward validation, and deterministic local inference on Modal. [Research and validation](https://github.com/zichenz7/Optiver-Explaining-Markets-Showcase/blob/main/RESEARCH.md) · [Public model card](https://explainingmarkets.ai/models/s_e01164bd47b2)
- **[Sandia Data Challenge](https://github.com/zichenz7/Sandia-Data-Challenge)** — Statistical modeling of manufacturing scrap risk in R, using a binomial GAMM with spatial and plate-level effects. Our team placed in the top 10 of 40.
- **[Smart Calendar Assistant](https://github.com/zichenz7/Smart_Calendar_Assistant)** — A Google Calendar add-on for task organization, priority ranking, and rule-based break suggestions. I led a 7-member ACM SIGCHI team, focusing on feature design, task allocation, and feature demonstrations. [Technical overview](https://github.com/zichenz7/Smart_Calendar_Assistant/blob/main/ENGINEERING.md)

- **[Table Tennis Equipment Recommender](https://github.com/zichenz7/Table-tennis-recommendation-system)** — A Python decision-support tool for blades and rubbers, using user-weighted TOPSIS, explicit cost criteria, and radar charts. I served as team lead, responsible for feature design, task allocation, progress tracking, and organizing team meetings. Includes reproducible offline examples and algorithm regression tests. [Method and validation](https://github.com/zichenz7/Table-tennis-recommendation-system/blob/main/METHOD.md)
